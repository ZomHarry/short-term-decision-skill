## 三、已渲图核对的原文（项目四）

**第 11 页（成本无差别点）**
> 成本无差别点是指两个备选方案预期相关成本相同时的业务量。
> 适用情境：不同方案预期收入相同，且有各自的业务量优势区间（尤其是业务量未知情况）。
> 应用程式：(1) 确定不同方案的成本业务量模型 Y₁ 和 Y₂；(2) 令 Y₁＝Y₂ 求出 x₀；(3) 根据 x₀ 分区间做出决策。

**第 11 页（自制外购）**
> 由于所需零配件的数量对自制方案或外购方案都是一样的，因而通常只需要考虑自制方案和外购方案的相关成本高低，在相同质量并保证及时供货的情况下，就低不就高。

**第 16 页（最优批量的年成本构成）**
> 最高储存量 = Q − (Q/X)·Y = Q(1 − Y/X)
> 年平均储存量 = ½·Q(1 − Y/X)
> 年储存成本 = ½·Q(1 − Y/X)·C
> 年准备成本 = (A/Q)·S
> 年成本合计 T = ½·Q(1 − Y/X)·C + (A/Q)·S

**第 17 页（最优批量与最低成本）**
> 最优生产批量 Q* = √( 2AS / [C(1 − Y/X)] )
> 最优批次 = A / Q*
> 最低年成本合计 T* = √( 2ASC(1 − Y/X) )

## 四、需与教材核对的口径

以下五处在不同教材版本中处理不一致，本仓库采用讲义口径，并在相应文件中标注：

1. **外购相关成本**：讲义写"买价"；扩展口径是否含运费、检验费——本仓库按题意处理，题面给了就计入专属支出。
2. **单位变动成本口径**：是否含变动销售费用。特殊订货中通常剔除本批不发生部分。
3. **专属成本的位置**：贡献毛益分析法中作减项（剩余贡献毛益），成本无差别点法中并入 a。
4. **机会成本计量**：用贡献毛益而非净利润（与讲义一致）。
5. **瞬时入库（Y＝0）**：经济批量退化为 √(2AS/C)，属特例，需确认教材是否单独给出。
