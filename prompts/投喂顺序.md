# 投喂顺序（复制粘贴用）

天工 AI 的单条消息有长度上限，整仓一次性粘贴会被截断。按下面顺序发 **7 条消息**：第 1 条是任务书，第 2–7 条是文件。

每条消息的模板：

```text
===== 文件 2/6 开始 =====
路径：knowledge/formulas.md
用途：公式与符号说明
----- 内容开始 -----
（把文件全文粘在这里）
----- 内容结束 -----
===== 文件 2/6 结束 =====
```

## 消息清单

| 顺序 | 内容 | 说明 |
| --- | --- | --- |
| 1 | `prompts/打包任务书.md` 全文 | 让它先明确任务与产出物 |
| 2 | `prompts/system-prompt.md` | 最重要，篇幅最长，单独发 |
| 3 | `knowledge/formulas.md` | 公式库 |
| 4 | `knowledge/method-decision-tree.md` | 判断表 |
| 5 | `knowledge/common-errors.md` | 易错点 |
| 6 | `SKILL.md` | 技能正文 |
| 7 | `tests/test-cases.md` | 验收题 |

## 发完之后说这一句

```text
6 个文件已全部发送完毕。请按任务书第二节输出七件套，系统提示词控制在 3000 字以内。
```

## 如果它中途"忘记"前面内容

长对话中模型会丢上下文。补救办法：在第 6 条消息之后补一句

```text
请先复述：五步决策树的判断顺序、七段输出格式的段名、三种必须剔除的无关成本。
复述正确后再开始产出。
```

复述错了就说明它丢了内容，此时把 `prompts/system-prompt.md` 再发一遍。

## 投喂前的自检

- [ ] 每个文件都用了分隔标记，模型能看出边界
- [ ] 单条消息 < 4000 字（超了就按小节拆成两条，标记写成 3a/3b）
- [ ] 文件内容里没有残留的 Markdown 代码围栏冲突（如有，把内容里的 ``` 换成全角）
- [ ] 最后一条消息明确要求"输出七件套"，而不是开放式聊天
