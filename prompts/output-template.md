# 七段输出模板

复制下面模板填空。**七段缺一即不合格**；顺序不可调换。

```markdown
【题型识别】
<一句话：属于哪类决策 + 依据什么选择该方法>

【已知信息】
| 项目 | 数值 | 单位 | 备注 |
| --- | --- | --- | --- |
|  |  |  |  |
（缺失项写"未给"，不许留空）

【相关成本识别】
| 项目 | 是否相关 | 理由 |
| --- | --- | --- |
|  | 相关 | 该方案不发生则无此项成本，且方案间有差异 |
| 沉没成本（已发生） | 无关 | 任何决策都无法改变 |
| 联合成本（分离前） | 无关 | 分离与否都已发生 |
| 共同固定成本（分摊） | 无关 | 各方案金额相同，不随决策变化 |

【计算】
① 公式：
   代入：
   结果：
② …
（每步一行公式，公式 → 代入 → 结果，不跳步）

【结论】
选择 <方案>／接受／拒绝／继续生产／进一步加工。
主要依据：<差额金额> 元（<甲 − 乙>）。
临界条件：<当 xx 超过/低于 yy 时结论反转>。

【易错点】
1. <本题最易错处>，因为 <原因>。
2. …

【信息缺口】
- <变量名>：<缺失会导致什么后果>
（无则写"无"）
```

## 填写说明

- **题型识别**：只写一句，必须点出"用了哪个方法、为什么是它"，不要写题型定义。
- **已知信息**：只列参与计算的字段；无关字段（如联合成本）也要列出来并标"无关"，这本身就是判断的一部分。
- **相关成本识别**：理由列必须能对应两条标准之一（"不发生是否有此成本""方案间是否变化"），禁止只写"相关/不相关"。
- **计算**：中间值保留 4 位，最终结果保留 2 位或整数；金额带单位。
- **结论**：先动作后金额，再给临界条件；不要出现"建议考虑"这类模糊表述。
- **易错点**：针对本题具体数据，不写"注意审题"这类空话。
- **信息缺口**：写变量名与影响方向，而不是"信息不足"。

## 提交前自检清单

- [ ] 方法由路由树推出，且说得出为什么不是相邻方法
- [ ] 相关成本表的每条理由都能对应判定标准
- [ ] 沉没成本／联合成本／共同固定成本已显式剔除
- [ ] 成本无差别点方向正确（量大选固定成本高者）
- [ ] 每个数字可用题面数据复算
- [ ] 结论有动作 + 差额 + 临界条件（如有）
- [ ] 易错点是本题专属
- [ ] 信息缺口列全且未用假设填补
- [ ] 单位、正负号、小数位一致
