# Few-shot 示例

两个示例分别演示：**完整七段输出**、**信息缺失时的追问**。

---

## 示例 1：特殊订货（七段完整输出）

**用户输入**
> 甲公司生产 A 产品，年正常销量 8000 件，单价 100 元。单位成本资料：直接材料 25 元、直接人工 15 元、变动制造费用 12 元、固定制造费用 18 元（按 8000 件分摊）、变动销售费用 8 元。现有产能 10000 件。一客户愿以 72 元/件订购 1500 件，该批订单仅发生销售费用 2 元/件，另需专用模具 5000 元。是否接受？

**助手输出**

【题型识别】
特殊订货决策，用相关损益法。原因：产能有余，不影响正常销售，属"接受/拒绝"二选一且收入不同，比相关损益即可。

【已知信息】
| 项目 | 数值 | 单位 | 备注 |
| --- | --- | --- | --- |
| 正常销量 | 8000 | 件 |  |
| 正常单价 | 100 | 元/件 |  |
| 单位变动生产成本 | 52 | 元/件 | 25+15+12 |
| 单位固定制造费用 | 18 | 元/件 | 按 8000 件分摊，**无关** |
| 正常变动销售费用 | 8 | 元/件 | 特殊订单**不发生** |
| 特殊订单销量 | 1500 | 件 |  |
| 特殊订单单价 | 72 | 元/件 |  |
| 特殊订单变动销售费用 | 2 | 元/件 | 仅本批发生 |
| 专用模具 | 5000 | 元 | 专属成本，可避免 |
| 剩余产能 | 2000 | 件 | 10000−8000，>1500，不挤占正常销售 |

【相关成本识别】
| 项目 | 是否相关 | 理由 |
| --- | --- | --- |
| 单位变动生产成本 52 元 | 相关 | 不接受订单则不发生 |
| 特殊订单变动销售费用 2 元 | 相关 | 仅本批发生 |
| 正常变动销售费用 8 元 | 无关 | 本批不发生；且正常销量不受影响 |
| 固定制造费用 18 元/件 | 无关 | 总额不变，仅分摊率变化 |
| 专用模具 5000 元 | 相关 | 专属成本，接受才发生 |
| 机会成本 | 0 | 剩余产能充足，不挤占正常销售 |

【计算】
① 单位相关成本 = 单位变动生产成本 + 本批变动销售费用
　　= 52 + 2 = 54（元/件）
② 相关收入 = 72 × 1500 = 108000（元）
③ 相关成本 = 54 × 1500 + 5000 = 81000 + 5000 = 86000（元）
④ 相关损益 = 108000 − 86000 = **22000（元）**

【结论】
接受该特殊订单。
主要依据：相关损益 +22000 元 > 0。
临界条件：若订量增至挤占正常销售（>2000 件），每挤占 1 件增加机会成本 40 元（正常单位贡献毛益 100−60），结论将迅速反转。

【易错点】
1. 误把 18 元/件固定制造费用算进相关成本——它总额不变，只是被更多产量分摊，属无关成本。
2. 误把正常变动销售费用 8 元/件算进去——本批只发生 2 元/件，且不侵蚀正常销量。
3. 只看"72 < 完全成本 78"就拒绝——完全成本口径下 72 元确实亏，但相关成本口径下赚 22000 元。

【信息缺口】
无。（已给产能、专属成本、本批销售费用，足以判断。）

## 示例 2：信息缺失（先追问，不出结论）

**用户输入**
> 丙产品年销 6000 件，单价 80 元，单位变动生产成本 55 元，分摊固定成本 180000 元，账面亏损 30000 元。是否停产？

**助手输出**

【题型识别】
亏损产品去留决策，本应使用差量分析法，比较"继续生产"与"停产/转产"的差额损益。但题面信息不足以支持判断。

【已知信息】
| 项目 | 数值 | 单位 | 备注 |
| --- | --- | --- | --- |
| 销量 | 6000 | 件 |  |
| 单价 | 80 | 元/件 |  |
| 单位变动生产成本 | 55 | 元/件 |  |
| 变动销售费用 | 未给 | 元/件 | **缺口** |
| 分摊固定成本 | 180000 | 元 | 可避免比例**未给** |
| 账面亏损 | 30000 | 元 | 含 180000 分摊，不可直接采信 |

【相关成本识别】
| 项目 | 是否相关 | 理由 |
| --- | --- | --- |
| 单位变动生产成本 55 元 | 相关 | 停产即不发生 |
| 变动销售费用 | 待定 | 未给，直接改变贡献毛益 |
| 分摊固定成本 180000 元 | 待定 | 若为共同成本则无关；若有可避免部分则相关 |
| 停产后的产能用途 | 待定 | 转产/出租收益构成机会成本，直接决定结论 |

【计算】
仅能算到第一步：
贡献毛益 = (80 − 55) × 6000 = 150000（元）> 0
即：丙产品目前仍能弥补 15 万元固定成本。**但据此不足以得出"继续生产"的结论**，因为：
- 停产若可避免的固定成本 > 150000 元，则停产更优；
- 停产若可腾出产能转产，机会收益 > 剩余贡献毛益时，停产更优。

【结论】
暂不给出结论。现有数据只能说明"丙产品贡献毛益为正，账面亏损由分摊固定成本造成"，不能判定应否停产。

【易错点】
1. 把账面亏损 30000 元当作停产依据——该亏损含 180000 元分摊固定成本，与停产决策无关。
2. 算出贡献毛益 150000 元就直接说"应继续生产"——忽略了可避免固定成本与转产机会。

【信息缺口】
请补充以下 3 项，我即可给出确定结论：
① **变动销售费用**：元/件？（若有，贡献毛益将低于 150000）
② **分摊固定成本中可避免的比例**：停产时 180000 元里能省下多少？（若可避免额 > 剩余贡献毛益，则应停产）
③ **停产后产能的用途**：闲置、转产其他产品、还是出租？转产/出租的净收益是多少？（这是机会成本，直接与 150000 元比较）

补充后我将给出：继续生产 / 停产 / 转产 三者中净收益最高的方案，并列出差额。
